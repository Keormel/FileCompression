# Формат FCMP

Все числовые поля записываются в big-endian. Magic number равен `FCMP`. Текущая версия формата — `2`; версия `1` по-прежнему читается.

## Версия 2 (блочный поток)

Файл делится на независимые блоки (по умолчанию 1 МиБ), поэтому сжатие и восстановление файлов любого размера идут с ограниченным расходом памяти, а блоки можно обрабатывать параллельно на нескольких ядрах.

```text
заголовок  >4sBBHQHI  magic, версия (2), алгоритм, флаги (0), исходный размер, длина имени, размер блока
имя        UTF-8 имя файла
блок 1..N  >BIII      алгоритм блока, исходная длина, длина metadata, длина payload; затем metadata и payload
конец      >BIII      все поля равны 0
трейлер    32 байта   SHA-256 исходных данных
```

Идентификаторы алгоритмов: `1` Huffman, `2` LZW, `3` RLE, `4` stored. Каждый блок сжимается отдельно; если сжатие не уменьшает блок, он записывается как `stored`. Алгоритм в заголовке — выбранный алгоритм, если хотя бы один блок им сжат, иначе `stored`.

Huffman metadata содержит JSON-частотную таблицу блока, LZW metadata — ширину кода `16` (словарь начинается заново в каждом блоке), у RLE и stored metadata пустые.

Распаковщик проверяет: известную версию и алгоритмы, длину каждого блока (не больше размера блока; сжатый блок строго меньше исходного), сумму длин блоков относительно исходного размера, отсутствие лишних байтов после трейлера и SHA-256. При потоковой выдаче последний блок отдаётся только после совпадения контрольной суммы.

## Версия 1

Фиксированный заголовок `>4sBBHQH32sIQ` (magic, версия, алгоритм, флаги, исходный размер, длина имени, SHA-256, длина metadata, длина payload), затем имя, metadata и payload одним блоком. Размер ограничен 256 МиБ. Этот формат только читается.
