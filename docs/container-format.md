# Формат FCMP

Все числовые поля записываются в big-endian. Magic number равен `FCMP`, версия текущего формата `1`.

После фиксированного заголовка идут:

1. UTF-8 имя файла;
2. metadata алгоритма;
3. compressed payload.

Заголовок содержит идентификатор алгоритма (`1` Huffman, `2` LZW, `3` RLE), исходный размер, длины последующих областей и SHA-256 исходных байтов. Huffman metadata содержит JSON-частотную таблицу, LZW metadata содержит ширину кода `16`, RLE metadata пусты.

Распаковщик отклоняет неизвестную версию, неверные длины, небезопасное имя, поврежденные данные, несовпадение размера и checksum.
