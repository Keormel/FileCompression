# Алгоритмы

Все три алгоритма являются lossless и работают с произвольными байтами.

## Huffman

Строится частотная таблица, затем минимальная очередь объединяется в бинарное дерево. Более частые байты получают короткие коды. В FCMP сохраняется таблица частот и число значимых битов. Сложность построения составляет `O(n + k log k)`, где `k <= 256`.

## LZW

Последовательность заменяется кодами словаря. Начальный словарь содержит 256 байтов, код занимает 16 бит, максимальный код равен 65535. Decoder восстанавливает словарь синхронно с encoder. Амортизированная сложность линейна по числу входных байтов.

## RLE

Каждая серия представляется парой `uint32 count + byte value`. Алгоритм очень эффективен для длинных серий, но увеличивает случайные данные из-за служебных пяти байтов на каждую серию. Сложность кодирования и декодирования `O(n)`.

PNG, JPEG и PDF часто уже сжаты, поэтому повторное сжатие этими учебными алгоритмами может дать отрицательную экономию.
