# Протокол

TCP-фрейм начинается с 4-байтной big-endian длины. JSON-команды и бинарные FCMP-контейнеры передаются отдельными фреймами. Команды: `register`, `send`, `receive`, `list`; ответы: `registered`, `sent`, `file`, `incoming`, `error`, `received`.

Размер одного фрейма ограничен 256 MiB, чтение и запись имеют таймаут 30 секунд. Сервер валидирует FCMP до помещения в inbox. Получение использует ACK: контейнер удаляется из очереди только после успешной отправки клиенту. Это учебный relay без TLS и аутентификации.
